# 衡见 HengSight

> 面向中国资产的 AI 投资研究与决策支持软件

## 项目简介

衡见旨在辅助个人投资者整理公开市场信息、理解政策与市场变化、形成结构化研究观点，并通过模拟验证和持续复盘改善投资决策过程。

本项目当前聚焦中国资产研究，不连接券商，不执行真实交易，也不提供收益保证。

## 软件用途

- 汇总公开新闻、政策、行情和研究信息；
- 提炼影响中国市场的核心线索；
- 生成包含证据、反方观点、风险和失效条件的研究记录；
- 支持模拟投资组合、预测记录和历史复盘；
- 帮助用户形成更可追溯、更有纪律的投资决策过程。
