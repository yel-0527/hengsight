# 衡见 HengSight

> 探索 AI 辅助研究与可控模拟操作的学习型工程项目。

> 本公开仓库用于介绍项目。源码目前不公开，不提供安装包、公开服务接口或公众使用授权。

## 项目简介

衡见希望探索：如何让 AI 帮助用户整理信息、理解分析依据，并在用户明确授权的范围内完成可控、可停止、可追溯的模拟操作。

项目仍处于早期原型验证阶段。目前重点不是选股、策略或收益，而是先验证授权、模拟执行、停止、恢复和操作记录能否正确协作。

## 长期探索方向

以下是项目希望探索的方向，**不代表已经实现，也不是交付承诺**：

- 整理市场信息，辅助理解与研究；
- 展示分析依据、不同观点和风险；
- 由用户选择需要辅助或自动处理的环节；
- 在明确授权、范围和限制下进行模拟代理操作；
- 保存逐用户操作记录，支持查询与复盘。

真实行情、真实模型接入及真实交易不在当前原型范围内；后续是否开展，需另行评估条件与风险。

## 当前正在验证什么

当前切片仅使用六个虚拟账号、合成数据和假模型，验证：

- 用户身份与账号隔离；
- 授权范围、额度及有效期检查；
- 资金预留、模拟成交和记账；
- 操作编号、重复请求与结果查询；
- 停止、核对及明确恢复；
- 逐账号保存操作与实施记录。

这些验证不能证明投资有效，也不代表软件已具备真实使用条件。

## 当前进度与限制

部分核心逻辑、数据库事务和网页接口已通过定点自动测试。

浏览器实际操作、真实进程中断、备份恢复及完整验收仍有待完成。当前页面是便于检查流程的临时测试面板，不是最终软件界面。

项目尚未交付正式可用版本，不向公众开放注册、下载或试用。
